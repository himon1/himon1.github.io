About关于

The short version简短版

I am an undergraduate in Computer Science at Tsinghua University, working with the Intelligent Technology and Systems Lab (THUIR). My work sits between information retrieval and large language model evaluation: how a system builds memory from interaction, when a piece of feedback should persist, and how to design benchmarks that reveal capability boundaries instead of merely ranking models. 我是清华大学计算机系本科生，目前在智能技术与系统实验室（THUIR）参与研究。我的工作位于信息检索与大模型评测之间：系统如何从交互中构建记忆，一条反馈应当在何时持续生效，以及如何设计能够暴露能力边界、而不只是给模型排名的评测。

My current focus is continual learning from long-horizon feedback. I am interested in the gap between declarative memory — recalling facts and preferences — and procedural memory — learning how to act from correction. A good evaluation should tell us not only whether feedback helps the current task, but whether it is reused in the right future cases and withheld from the wrong ones. 目前我关注长程反馈驱动的持续学习，尤其关心陈述性记忆（记住事实与偏好）与程序性记忆（从纠正中学会如何行动）之间的差距。好的评测不应只回答“反馈是否改善了当前任务”，还要回答它是否被用在了正确的未来场景里，以及是否被错误地越界复用。

I care about reproducible evaluation tooling, honest negative results, and systems that are simple enough to understand end to end. Before research, I built retrieval and crawling systems from scratch to learn where the abstractions actually come from. 我在意可复现的评测工具、诚实的负结果，以及简单到可以被完整理解的系统。在正式进入研究之前，我从零实现过检索与爬虫系统，想弄清楚那些抽象究竟从哪里来。

THUIR · Tsinghua 2026.06 — 2026.09 Research term研究阶段

Enhancing MemoryBench for Continual Learning

Rethinking what LLM memory benchmarks actually measure. I worked on extending MemoryBench from declarative recall toward procedural, feedback-driven continual learning — structuring multi-session episodes, analysing why simple retrieval baselines rival specialised memory systems, and comparing on-policy with off-policy memory updates. 重新审视大模型记忆评测究竟在测什么。我参与将 MemoryBench 从陈述性回忆推进到程序性的、反馈驱动的持续学习：设计多 session 的任务片段，分析为什么简单的检索基线能够比肩专门的记忆系统，并比较 on-policy 与 off-policy 的记忆更新方式。

  • AI Memory
  • Benchmark Design
  • User Simulation
Abstract展开摘要

MemoryBench organises evaluation as a loop between a task provider, a user simulator, the system under test, and a performance monitor. Its most useful move is to separate declarative memory from procedural memory: most systems retrieve facts reasonably well, but few turn feedback into a reusable policy. In this project I helped design feedback-centric episodes and examined when retrieved context, rather than a sophisticated memory module, is enough. MemoryBench 把评测组织成 Task Provider、User Simulator、被测系统与 Performance Monitor 之间的循环。它最有价值的一点，是把陈述性记忆与程序性记忆分开：多数系统都能较好地检索事实，但很少有系统能把反馈转化为可复用的策略。在这个项目里，我参与设计以反馈为中心的任务片段，并考察在什么情况下检索到的上下文本身就足够，而不需要复杂的记忆模块。

Long-Horizon Feedback Learning

Can a system identify the persistent semantics of user feedback, reuse it in genuinely applicable future cases, and avoid stale or out-of-scope reuse? I am designing evaluations around this question using matched applicable / non-applicable probes. 系统能否识别用户反馈中持久有效的语义，在真正适用的未来场景中复用它，同时避免过期或越界复用？围绕这个问题，我正在用成对的“适用 / 不适用”探针设计评测。

  • Continual Learning
  • Feedback
  • Evaluation
Abstract展开摘要

Feedback is not the same as preference. A single comment can mix task quality, audience, and duration: “This email is too long; keep executive updates to five sentences from now on.” I am formalising feedback scope along temporal horizons (response, session, artifact, project, indefinite) and applicability predicates (user, task family, audience, domain), then measuring both helpful reuse and harmful over-generalisation. 反馈并不等同于偏好。同一条评论可能同时包含任务质量、受众与时效性：“这封邮件太长了；以后给高管写进展时控制在五句话以内。”我正尝试把反馈的适用范围形式化为时间跨度（当前回答、会话、产物、项目、无限期）与适用谓词（用户、任务族、受众、领域），并同时测量有益复用与有害的过度泛化。

Reading & reproduction 2026 — Exploration探索

Weakness Discovery for Model Evaluation

Most benchmarks rank models; fewer locate the specific capabilities a model lacks. I am reading and reproducing weakness-oriented evaluation methods that iteratively search for failing inputs and feed failures back into test generation. 多数 benchmark 用于给模型排名，却较少定位模型具体缺失的能力。我正在阅读并复现以“弱点发现”为导向的评测方法：迭代搜索失败输入，再把失败案例反馈给测试生成。

  • LLM Evaluation
  • Capability Boundaries
  • Iterative Search
Abstract展开摘要

Work such as AUTODETECT frames evaluation as a loop between an examiner, a questioner, and an assessor: build a taxonomy of tasks, generate targeted probes, score responses, and turn low-scoring cases into new search seeds. I am interested in whether such loops produce transferable diagnoses or merely overfit to a judge, and how to make discovered weaknesses actionable for training. AUTODETECT 一类工作把评测组织为 Examiner、Questioner 与 Assessor 之间的循环：构建任务知识体系、生成针对性问题、给回答打分，再把低分案例变成新的搜索起点。我关心这种循环产生的是可迁移的诊断，还是仅仅过拟合了某个 judge，以及如何让发现的弱点真正可用于训练。

LeCaRD TF-IDF Retrieval

A from-scratch TF-IDF vector-space retrieval system on the LeCaRD Chinese legal case dataset. Character-level tokenisation, sublinear TF, local IDF and cosine ranking — no retrieval framework, no black box. 在 LeCaRD 中文法律案例数据集上，从零实现的 TF-IDF 向量空间检索系统。字符级切分、次线性 TF、局部 IDF 与余弦排序——不使用检索框架，也不调用黑盒。
